Installing the SecureOS Netboot Server on a server using a bootable USB drive.
Before you begin, make sure you have the following:
• A Server to install SecureOS
• A bootable USB drive (created in DD mode)
• Active internet connection (through LAN only)
• A LAN cable (connected to a network with internet access)
• Installation key (this key is used for authentication; it can be used only once)
Installation Steps:
Step 1: Create a Bootable USB Drive
• Use BootMediaCreator to write the ISO to your USB drive using DD mode.
⚠Note: - Once written in DD mode, the USB will not be readable or editable via File
Explorer — this is normal.
Step 2: Boot the Target System
• Insert the bootable USB into the target laptop/server.
• Boot the machine from the USB (you may need to select the USB from the boot menu).
Step 3: Start the Installation Process
• Once the system boots from USB, a series of command-
line messages will appear.
• Wait until the following screen appears:
Installing SecureOS Netboot Server
You don’t need to do anything on this screen. The
installation process will start automatically please
wait patiently — this may take some time.
Network Configuration (Black Screen Phase)
• After some time, a black screen will appear asking you to enter:
 IP Address
 Gateway
 DNS
 Key
• Type the details and Press Enter.
󱟑 Note: - Make sure the LAN cable is properly connected and the IP address
has internet access. This step downloads essential system files — if the internet
disconnect, the installation may fail and the OS won’t work properly.
Step 5: Completing Installation
• Once the process is done, the system will reboot automatically.
• After reboot, you’ll see the SecureOS screen.
⚠Note: - After OS is installed, the screen
may remain blank for a while. Do not
force shutdown of server. Wait till login
screen appears.
