Once the OS is installed and you have got the login screen on the NetBoot server, now
you are ready to access the NetBoot dashboards.
Accessing Netboot Dashboard Using Peer-to-Peer
Network
Take one Ethernet cable and connect it directly from the Netboot Server Ethernet port to the
Windows machine Ethernet port. After connecting the cable, configure the Windows machine
with a static IP address in the same network range as the Netboot Server.
For example, if the Netboot Server IP address is 1.1.1.2 then set the Windows machine IP
address to 1.1.1.3 with subnet mask `255.255.255.0`.
After setting the IP address, open Command Prompt on the Windows machine and run the
ping command to verify connectivity with the Netboot Server. If the server responds
successfully, the peer-to-peer connection is working correctly. Now follow the below
process.
